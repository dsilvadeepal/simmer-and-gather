# Agentic build coverage

Updated November 7, 2026. One bounded LangGraph workflow coordinates typed tools and deterministic services.

| Concept | Implemented | Remaining boundary |
| --- | --- | --- |
| Context and memory | Owner-scoped gatherings, helpers, versioned recipe snapshots, plans and approvals; scoped Notion collection | Multi-user product access is deferred |
| Tools | Recipe preparation, Notion reads/persistence, calendar availability, scheduling, validation and checked alternatives | Paid interpretation is optional; writes remain explicit application actions |
| Orchestration | Bounded LangGraph planning with independent constraint validation and supported OR-Tools fallback | Search is not exhaustive or a proof of infeasibility |
| Human approval | Read-only previews; accepting a swap saves a newly rechecked plan; calendar approval is separate | Controlled live booking acceptance remains a release task |
| Evaluation | Configured local traces and code-based LangSmith experiments, plus DOM interaction regressions | No LLM judge, physical cooking validation or hosted reliability claim |

See [latest results](reviews/current-evaluation-results.md) and [build plan](superpowers/plans/2026-10-27-hosting-demo.md). Course credits support bounded experiments; no vector database, additional agent or second tracing service is required. Jev remains optional and unselected.
