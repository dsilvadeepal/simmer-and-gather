# Schedule-first UI design

See the current [PRD](../../../PRD.md) and [architecture design](2026-10-27-simmer-and-gather-design.md). Schedule opens first; Menu, Shopping and Finishing are secondary views. Continuous work uses one time block; genuine breaks stay visible. Show active versus elapsed time clearly, with quantities and expandable practical instructions. No protected-time editor, recipe-import panel or separate pantry-entry section. Read-only alternatives must not modify shopping state.
