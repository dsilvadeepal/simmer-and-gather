# UX critique — October 28, 2026

Method: Superpowers design review of the actual laptop and phone screens. Recommendations below are proposed, not approved redesign requirements.

## Diagnosis
Warm palette and restrained branding work. The hierarchy still resembles a landing page followed by a system report. The Prep plan destination should prioritize the host's next practical decisions and session schedule.

## Changes in priority order
1. Replace the tall marketing hero with gathering name, arrival date/time, guest count and concise buffer status. The schedule should be visible in the first screen.
2. Put the prep schedule first. Keep Menu, Shopping and Finishing as secondary sections/tabs; avoid repeating the complete menu before every visit to the schedule.
3. Group tasks by day/session. Show a date once, a planned-effort versus allowance summary, then compact action rows. Preserve gaps and return attention in details. Show required presence separately from elapsed window when they differ.
4. Use readable days and hours: Friday,45min planned /2h available, with actual session window. Empty prep days are available capacity, not scheduled work.
5. Simplify product copy. Replace revision numbers, entered constraints, source-review boilerplate and repeated selected-dish labels with concrete outcomes and targeted exceptions. Keep estimates and material uncertainty accessible.
6. Make actions state-dependent: Generate proposed plan only before a plan exists; Update plan after edits; Recheck availability as secondary. Calendar saving follows review in one clear area, retaining server-side exact approval.
7. Menu quantities should emphasize portions and primary ingredients. Showing ghee or ginger merely because they appear first is poor information prioritization. Source links belong behind compact recipe names; use accurate attributed thumbnails when available.
8. Retain warm ivory/green palette, use serif only for a modest gathering heading, sans-serif body16px and restrained metadata14px. Reduce oversized vertical padding and repetitive card borders. Add small consistent recipe/category icons, not decoration on every row.

## Already applied at the user's request
- Removed Previous proposal / revision history from the hosting screen; retained internal recovery records.
- Default daily prep allowance is120min for weekdays and weekends; explicit overrides and one-hour buffer remain.

## Recommended approach
Schedule-first workspace: compact gathering header → daily effort summary → day/session groups → expandable task details. Menu and shopping are readily reachable secondary views. An alternative is a single printable document with anchored sections; simpler for export but more scrolling during cooking. Recommend schedule-first for laptop planning and phone consultation. Do not implement the broader redesign until direction is approved.
